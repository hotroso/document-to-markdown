# Security Policy

## Reporting a Vulnerability

If you discover a security vulnerability in **document-to-markdown**, please do not open a public GitHub issue with exploit details.

Instead, report it privately via GitHub Security Advisories on [hotroso/document-to-markdown](https://github.com/hotroso/document-to-markdown/security/advisories/new) or email `hotrogiaiphapso@gmail.com`.

Please include:
- A clear description of the vulnerability and potential impact
- Steps to reproduce (minimal sample file or command, if applicable)
- Affected version(s)

You can expect an acknowledgment within 72 hours.
